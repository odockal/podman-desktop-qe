# Namespace workflows

These runbooks cover the cluster-wide **Namespaces** page and how its selected
namespace controls namespaced Dashboard pages.

| Workflow | Runbook | Resources | Functional outcome |
| --- | --- | --- | --- |
| Namespace isolation lifecycle | [Namespace isolation lifecycle](namespace-isolation-lifecycle.md) | Namespace → ConfigMap → Pod | Selecting the namespace shows its workload only; deleting the namespace removes its namespaced resources. |
